## Statistical interpretation audit

The following checks apply the experiment-design skill's interpretation guide. No new inferential calculation was performed; these are protocol defenses and limits on archived interpretation.

| Hazard | Project-specific correction |
| --- | --- |
| Simpson's paradox | Stratify natural versus matched histories, feedback regimes and task difficulty; do not pool a composition change into estimator improvement. |
| Ecological fallacy | A method-level average does not establish that every history or specimen benefits; report conditional and per-unit effects. |
| Berkson/selection bias | Matching changes the population; preserve acceptance rates and a separate natural-history cohort. |
| Collider bias | Do not condition evaluation on future task success, solver survival or oracle action disagreement. Current matching uses pre-outcome observations and has a scoped estimand. |
| Base-rate neglect | Report the prevalence of memory-relevant regimes in natural histories; paired mechanism examples cannot estimate it. |
| Regression to the mean | Freeze pair selection, decision cuts and model selection before final data; unusually large pilot effects need fresh confirmation. |
| Survivorship bias | Preserve failed seeds, invalid solves, timeouts and constraint violations; define denominator and failure handling prospectively. |
| Look-elsewhere effect | One primary contrast per stage; adjust the declared secondary family; do not search many tasks then present the best as confirmatory. |
| Forking paths | Record utility, thresholds, history windows, action library and sample-size changes on independent pilot/validation data before final generation. |
| Correlation versus causation | Histories are physically intervened on with controlled parameters and common future commands; passive correlations alone cannot identify the mechanism. |
| Reverse causality | Maintain causal command/acquisition/delivery timestamps and forbid future achieved motion or observations from entering predictions. |

Additional unit checks: frames, windows, future branches and network seeds are not independent physical observations. Material-level claims require independent material clusters. A narrow interval under a fixed synthetic law does not establish population-wide material validity. A degenerate binary bootstrap interval is not an equivalence result.
