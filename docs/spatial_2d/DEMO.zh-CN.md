在 VS Code 打开项目目录，执行 **Dev Containers: Reopen in Container**。
选择 **Python Environments > venv (Python 3.11.9)**，确认路径为 `/opt/venv/bin/python`，然后 **Restart > Run All**。
当前使用 Linux 原生内核，不需要启动外部 Jupyter 服务。构建命令见 [容器指南](CONTAINER.md)。
Windows `.venv` 和旧记录保留，旧环境操作见 [实现说明](README.md#legacy-windows-environment)。

默认 Run All 会实际重新求解一遍轻量主过程；物理收敛检查、预测和窗口扫描使用已完成的缓存，并明确标注 REPLAY。
新的后续动作、噪声或激励条件通过按钮计算。拖动时间滑条只回放；不会重复启动实验。
无缓存的完整小预实验实测 72.34 秒；8 段历史、2 个动作、2 档噪声的小批量执行约 175 秒，部分已有条件使用缓存。
Linux 干净内核自动检查实测 8.71 秒；VS Code 原生重启后 Notebook 主体 6.40 秒，其中新空间求解 1.49 秒。
播放、暂停、滑条、重置、后续动作和噪声切换已实际验证；Fast press 强制重算 6.90 秒。
本轮 [验证记录](CONTAINER_VALIDATION.md) 与旧 Windows 记录分开保存。

投屏时可按 Ctrl+B 收起侧栏，让网格和三条曲线完整显示。Pause 保留当前帧，Reset 回到起点。
Linux 容器的原生 Restart 已通过；旧 Windows 后端的重启限制仍记录在实现说明中。

## 三分钟讲解顺序

**0:00–0:50：看物理过程。** 播放加载、保持、释放、等待和再接触。强调网格是实际 FEM 求解；侧向运动不是预设动画。
命令位置和实际位置不同。释放后接触力为零，但材料内部场和侧向形变仍在恢复。
这是小应变、准静态二维物体，加上有质量和驱动柔顺性的压头；不是完整机械臂或真实材料验证。

**0:50–1:40：看当前观测与内部状态。** 两段历史由真实可执行动作生成。当前位置、速度和力相同，侧向残差约 2.18 μm，
在预先声明的 5 μm 匹配带内。内部场不同，后续同一压入命令产生约 5.58 mN 的力响应 RMS 差异。
细网格得到约 5.60 mN；两网格的“响应差值曲线”相差约 0.38 mN RMS。
注意：匹配带不是量化传感器，方法仍能利用侧向残差；不能据此声称“完整即时观测完全没有信息”。

**1:40–2:25：换后续动作。** 从相同合法检查点选择 Slow press 或 Fast press，再点运行。
观察瞬时估计、0.2 秒观察器、全历史经典重放和真实状态参考的实际预测曲线。
检查点处于脱离接触状态，所以 Hold/Release 的力接近零，是正常的负对照。
真实状态参考使用特权内部场，只用于相同动作下的比较，不是所有控制策略的最优上界。

**2:25–3:00：回答历史需要多长。** 无噪声验证历史中，0.1–0.2 秒已达到约 0.3–0.4 mN 的误差。
但打开标称噪声，短窗口会变差；8 段测试历史上的 0.2 秒观察器平均误差甚至高于瞬时估计。
因此当前结果不支持“必须长序列”或“必须神经网络”。全历史重放很准，主要因为模型参数与初始松弛状态已知。
