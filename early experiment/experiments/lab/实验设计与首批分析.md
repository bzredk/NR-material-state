# 首个实机时段：让材料现象决定学习对象

本次新增的是**可排进实验室时段的执行层**：一页英文执行卡、含6个锚点的30条总顺序、统一参数填写表、按实际参数计算耗时与阶段路径的脚本，以及逐尝试CSV合并入口。原24条条件、随机顺序、本构拟合与绘图工具均复用，原目录不修改。实机操作和设备驱动由实验室安排，本轮没有生成新的材料仿真、启动训练或伪造实测记录。

## 研究判断

刚完成的闭环衔接中，冻结历史模型在没有后续反馈时，相对当前观测模型的跨控制力预测RMSE降低91.6%；共同撤离与接触反馈后，额外行动收益不足，完成时间差只有约−0.0029 ms。共同观测器也会扰动原本准确的初态，因此不能把这个负结果概括成“反馈总能恢复真实材料状态”。

首批真实数据优先回答：**在同一后续压合动作下，高幅/超调预压与不同等待留下什么可重复的响应差异；哪些差异需要改变材料演化规律，而不只是重新估计固定规律的初态？** 优先候选仍是状态依赖恢复速率，但宽固定谱、静态非线性和QLV必须作为竞争解释。材料规律筛选先行；不要先要求动作收益成立才允许研究机制，也不要把材料预测改善当作已经获得行动价值。

推荐可追溯、无涂层的慢回弹开孔PU，P0用于预试验、S1完成正式矩阵；同批备用样保留。普通快回弹PU是后续独立对照，不占用这24条。依据是已有实测研究显示PU压缩恢复和松弛响应具有明显材料差异，多阶段响应也可以由经典有效模型解释；这些事实支持选材与保留竞争模型，**不证明当前样品一定存在状态依赖速率**。[Yoneda等，2014](https://www.jstage.jst.go.jp/article/senshoshi/55/11/55_857/_article/-char/en)；[Aou等，2017](https://www.sciencedirect.com/science/article/pii/S0032386117303786)。

这些论文的样品、几何和极端加载条件不直接移植。更详细的方法边界仍使用原包中的文献记录；本轮只核对了直接影响选材的来源，没有新做广泛文献审计。

## 干预、观测和主要混淆

| 对象 | 首时段中的含义 |
|---|---|
| 隐藏物理状态 | 内部应变、软化、孔隙相关记忆等候选；不把仿真中的z当成实测标签 |
| 动作 | 已知计划与实际发出的压头命令，分开保存 |
| 观测 | 实际压头相对基座位移、法向力、时间；可选表面高度 |
| 上下文 | 同一试样/几何/界面/温度、固定控制模式、实际延迟和滤波 |
| 主要干预 | 2个预压终点幅度 × 2条加载路径 × 3个空中等待 |
| 重复单位 | 同一试样上两个完整块的技术重复；总体独立试样数仍为1 |

“等待”必须写清：CSV的`wait_s`是压头到达公共空中位置之后的dwell；实际无接触恢复还包括撤离尾段和再次接近的一部分。两个都保留。若往返运动已耗尽所谓“短时恢复”，应在预试验调整整个撤离/接近方案或承认观测不到更快尺度，不能只把等待栏改成更小数字。

现有CSV工具给出的脱离/重接触时刻是预试验阈值与持续时间下的力信号代理，附判据和时间误差，不称为未测得的几何真值。

充分恢复表面是固定坐标参考。空载TCP不能代替泡沫表面高度；光学高度恢复也不能单独证明内部状态完全恢复。正式采集前用最强预压后的参考响应验证复位时间，正式块中用锚点观察漂移。无相机时，使用独立复位后的单次接触预试验，不在一次恢复过程中反复触碰而仍称“自由恢复”。

## 每组记录区分什么

| 对照或记录 | 具体比较 | 可能支持什么 | 尚不能据此声称什么 |
|---|---|---|---|
| L/H，固定程序与等待 | 同一probe下的接触位置、峰值、保持曲线 | 幅度改变了残留状态或静态映射；跨幅度留出检验模型 | 高幅留出不自动等于整个应变区间外推 |
| slow/overshoot，固定A与等待 | 终点、终末保持相同，路径不同 | 当前位置不足以解释未来响应；检验路径记忆 | 超调还改变路径和受载时长，不能只归因于峰值 |
| short/middle/long，固定A与程序 | 响应如何随无接触恢复变化 | 固定谱是否可统一传播状态；变速率候选是否有剩余解释力 | 曲线“变快/变慢”本身不是状态依赖速率证据 |
| H/overshoot/short：e09、e23 | 预定重点展示的两个完整重复 | 最强可逆历史后的短时响应、可观测窗口 | 不能只挑这两条拟合或只报告正结果 |
| 原加载及保持阶段 | 用实际位移判断力变化 | 静态非线性、松弛时间尺度；执行器跟踪偏差 | 实际位移在变时不能直接称为恒应变松弛模量 |
| a01…a06，相同小参考载荷 | 块前/中/后原始响应与零点 | 复位、漂移、装夹或不可逆变化的具体线索 | 锚点不是六个独立样品，也不进入24条拟合 |
| 每个条件的两次技术重复 | 原始曲线和实测运动并列 | 先导重复尺度及可检测效应 | 不能对采样点bootstrap来伪造试样置信区间 |

原顺序不重抽。高幅/超调/短等待的优先级体现在预试验窗口选择、预定主图和后续残差检查，不体现在删减其他条件或额外采集有利记录。第一块含全部12个条件；若跨日完成第二块，日期与重复层次不能独立估计，必须保留会话和标定上下文。

## 参数如何落地

英文计划给出完整校准与操作步骤，`session_plan/parameter_form.csv`是唯一生成采集计划的物理参数入口。所有加载、等待、复位及设备值初始为空；只有预约时长、准备/交接/余量等行政预算有可改默认值。

| 参数组 | 决定依据 |
|---|---|
| A_L、A_H、κ、probe目标 | 实际厚度与预试验可逆工作区；保留足够变化。κA_H和共同probe都在已测工作区内 |
| 加载/撤离/probe速度 | 两个实用速度的跟踪与带宽对比；正式24条不增加速度这个因素 |
| 终末保持、probe保持 | 既覆盖快速变化，也保留可辨慢变化；若仍未稳定则记未达到平衡，不伪装静态测量 |
| 三个等待 | 自由恢复观测或独立单次探测；loaded relaxation常数不直接当unloaded recovery常数 |
| 复位与参考带 | 最强预压后的重复高度/参考响应；固定washout与6个锚点组合，不靠零力判断 |
| 接触阈值与持续时间 | 空载噪声、漂移和相关时间；这是分析接触阈值，不是设备保护力限 |
| 采样、控制、滤波、延迟、限值 | 实际硬件/软件配置和实验室既有规程，另记metadata与controller schedule |
| 拟合时间尺度和积分步长 | 数据带宽与记录时长，数据到达后依据预试验填写；不以这些分析设置阻碍采集 |

复位路线可选`optical_and_reference`或`reference_washout`。后者允许未测的光学高度带留空；新计划入口只对此做必要兼容，原拟合/检查代码原样保留。生成的`motion_segments_relative.csv`用于核对轨迹阶段、距离和预约耗时，不是机器人驱动程序。实际加速度约束、插值、坐标变换、阶段时间和计划可用性仍由设备日志记录。

## 第一批数据到达后的顺序

1. **第一条anchor和core到达即可接入。** 合并CSV后运行`first_batch.py inspect`。看原始命令、实际位移、力、单位、时钟映射、真实脱离、阶段标注。只修正足以影响解释的问题；不要依靠调整曲线时移来让模型拟合更好。
2. **每个完整块结束做原始图。** 检查锚点漂移、实际运动、完整交叉条件和复位证据。单块12条可以描述现象，但没有每条件重复性，现有runner不据此启动完整机制比较。
3. **24条完成后先比较重复与校准尺度。** 展示所有12对曲线差异、峰值/接触位置差异；按已记录的probe开始对齐，不按力峰对齐。不先滤掉最不一致的记录。
4. **只做本构条件预测，再比较规律。** 用已测实际位移驱动材料模型，不向预测段提供未来力修正。先L2和一个划分测实际拟合成本；随后L/S/Q的2、4、6模态与R2/SR2使用相同数据、评分窗口和初值预算。宽谱的数值不收敛不能算作科学失败。
5. **用完整交互留出。** 复用三个划分：高预压幅度、中央等待、超调程序分别整组留出。非测试条件的重复1拟合、重复2选模型；测试条件两个重复保留。中央等待是插值；三个划分重叠，不能当成三份独立确认。
6. **将原始现象、预测和残差联系起来。** 主图固定为e09/e23全过程；同时报告全矩阵等待效应、所有模型留出误差和残差随时间/压缩/历史的变化。不要只有平均误差排名。
7. **冻结下一批问题。** 只有候选跨条件改善超过重复差异和校准敏感度，并在独立试样、新日或新程序保留，才推进更灵活的学习。原包的校准敏感度`bF + Klocal bx + |dF/dt|local bt`是尺度诊断，不是概率置信区间。

| 观察到的证据 | 后续学习对象或处理 |
|---|---|
| 宽固定谱已解释完整矩阵，残差在重复/标定尺度内 | 保留经典演化与状态传播；不为这块材料增加网络 |
| S/Q稳定改善跨幅度预测，剩余瞬态可由固定谱解释 | 优先非线性静态/应变映射；不包装为新记忆 |
| R/SR击败验证集选出的最强固定律，尤其减少跨历史/等待的结构残差 | 优先低维正值状态依赖速率，再用独立新程序确认 |
| 多种短近期观测相近时，未来仍持续分离，现有低维律均失配 | 候选额外记忆变量；确认前先排除几何、界面、温度、同步和不可逆变化 |
| 改善材料规律后预测更准，但实际反馈消除了动作差异 | 保留机制与迁移预测贡献，限定行动主张 |

第二级命令条件力/运动预测和同反馈行动比较都留待执行器、观测链与实际任务标定后。规律增益与历史初始化增益分别做对照，不再把仿真中的50 ms、2个百分点或共用大协方差当作实机结论。

这批数据将决定值得学习的是静态映射、固定谱状态、状态依赖速率，还是额外记忆。它推进thesis-spine中的物理状态和演化规律；给LT的具体接口是可见历史、竞争解释、区分探针与实测差异，以及采集/等待/复位的时间成本，而不是提前给出复用保证。
