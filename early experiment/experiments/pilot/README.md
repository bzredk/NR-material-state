# 材料状态跨脱离、恢复与重接触：一维小型实验

2026-10-19。第一轮本地仿真；不包含实机结果或论文 novelty 证据。

核心问题：从过去力—运动记录接地的状态，是否能在未见等待时间下预测再接触的力与运动？本实验采用已知的双模态 Maxwell 生成系统，首先验证实现与评估流程。正确模型族的经典辨识是强基线，预期可以优于小型神经模型。

本轮已完成。结果与解释见 [简短实验报告](简短实验报告.md)：留出等待力 RMSE 为经典双模态 0.000190 N、材料状态学习 0.0382 N、GRU 0.1109 N、当前观测对照 0.1215 N。全部 9 次训练含验证约 15.1 分钟，5 项检查通过。

## 物理与符号

向下为正。`x` 是压头相对未变形表面的位移，`e` 是垫的实际压缩量，`z_i` 是 Maxwell 支路黏性延伸。

\[
E=\tfrac12 k_\infty e^2+\tfrac12\sum_i k_i(e-z_i)^2,
\quad \dot z_i=(e-z_i)/\tau_i,
\quad F=k_\infty e+\sum_i k_i(e-z_i).
\]

无接触时 `F=0`，自由表面压缩量一般非零；`z` 继续演化。接触时 `e=x`。约束是 `e-x>=0, F>=0, F(e-x)=0`。

已知执行器：`m*x_ddot=K*(u-x)-D*x_dot-F`，视为重力已补偿的一维阻抗装置。未来输入 `u` 是命令，实际 `x` 不等于命令。后向 Euler 每步同时求解执行器、材料及接触分支；不通过截断拉力后冻结形变来近似自由恢复。

这个模型是有效一维软垫模型，暂不包含摩擦、黏附、塑性、温度变化、变化接触面积、分布式材料形变或未知控制器。

## 学习与信息边界

训练 256 条、ID 验证 64 条，测试 128 组配对历史。前缀 3 s，未来统一 4.2 s，采样/积分间隔 0.02 s。

训练/验证等待范围 `[0.2,0.5]` 或 `[1.8,2.2]` s；留出范围 `[0.8,1.2]` s。属于训练范围内部的条件留出，不是长时间外推。测试 ID/OOD 共用同一个未见历史，只改变未来等待，其余重新压合命令一致。训练、验证、测试历史 ID 完全分离。

所有非 oracle 方法部署时只使用带噪历史与未来命令。训练时实际未来位移、力作为标签。`oracle_*` 和干净 `truth` 仅供评价／诊断。所有交互从已充分恢复的物理初态开始，这是一项明确先验。

- 经典模型：弹性、单模态、双模态；从训练集位移与力辨识本构参数，再从已观测历史积分状态。
- GRU：32 维编码器/递推记忆，学习力响应，接入与材料状态模型相同的已知执行器方程，完整自回归预测，无 teacher forcing。
- 材料状态：32 维历史编码器接地两维状态，同时学习正值刚度和时间常数；采用给定 Maxwell 结构。这一轮没有学习未知本构公式。
- Snapshot：相同网络参数量、相同物理解码器，只编码预测切点的当前观测。用于区分历史必要性与物理解码器收益。
- Oracle：真参数和预测切点的真状态，特权上界，不是可部署基线。

模型容量不同：GRU 力模型 8,305 参数，两个材料状态模型均 3,815 参数。神经模型按相同更新数和数据采样规则比较，不是严格等 FLOPs。物理结构与历史表示的贡献必须通过同结构消融判断。

## 指标与限制

主指标是按未来命令定义的再次压合开始后 1.2 s 内的逐轨迹力 RMSE，再跨轨迹平均。这样长时间零力等待不会稀释关键误差。另报位移 RMSE、峰值力误差、配对等待效应误差和全程误差。

置信区间使用优化种子与独立测试历史的分层 bootstrap。三种子只反映首轮优化不确定性；一个材料、一个控制器的结果不能推广到材料族或真实机器人。

`reset`/`freeze` 是固定已训练权重后的推断干预，不是各自重新训练的竞争模型。`no_history` 直接清零切点状态，不等于 snapshot 对照。核心物理状态与积分结构也是生成器的已知结构，好的结果首先说明机制和流水线正确，不能直接证明新方法的普适优越性。
