# Physical state transfer across future controllers

本目录是本轮的主要隔离实验（transfer_v2）。上一级保留先导诊断版本 transfer_v1，第二轮与材料机制先导实验的原始产物也保留。没有实机数据，没有启动机器人。设计修订及对原先切换瞬态解释的纠正见 `design_revision.json`。

## 运行

先按[安装指南](../../../../SETUP.md)准备 CUDA 环境，再按[运行手册](../../../REPRODUCING.md#e2--transfer-to-future-controllers)复制完整 E2 目录。在副本的 `v2` 子目录中，重算已保存模型的评估：

```sh
python experiment.py evaluate
python numerical_audit.py
python plot_results.py
python cases.py
python summarize_results.py
python decision_sensitivity.py
python audit_results.py
python qa_exports.py
```

输出固定为本目录的 `runs/transfer_v2` 和 `figures`。新训练前，按运行手册把副本里的旧 `runs/transfer_v2` 移到副本外，再依次运行 `profile`、`prepare`、`train`、`evaluate`。修改配置名称不会改变输出路径。保留父目录的 v1 记录，成本汇总仍会读取它们。

中断后使用 `python experiment.py train --resume`。该命令恢复优化器、学习率调度器和采样状态，已收敛模型自动跳过。测试入口拒绝未达到验证平台期的模型。首次调用 Numba 会编译，成本分析使用预热后的迭代。

PowerShell 启动器 `./run_experiment.ps1 -Stage evaluate -Python python` 会执行上述评估和导出步骤，并在失败时停止。

## 方法与信息接口

历史输入为 301×5 的 `[实际位置 m, 实际速度 m/s, 力 N, 命令位置 m, dt s]`。全部历史在同一已知控制器 K=2200 N/m、D=45 Ns/m 下由物理过程重放产生；两种历史的末端观测相同，但两模态材料内部状态不同。未来命令与已知 K、D 是预测条件，未来实际位置和力仅为训练标签或评价真值。

训练学习的只是神经网络参数：状态模型学习历史到两个 Maxwell 内变量的分配；材料刚度与时间常数沿用第二轮**训练集**拟合结果并固定，执行器质量及 K、D 已知。当前应力约束固定内状态的一个线性组合，网络只需学习剩余的一维分配。未来 K、D 从不进入状态编码器，在接触动力学求解器中生效。测试每段历史编码一次，广播到全部未来控制条件、等待和动作。

条件 GRU 使用同样的传感历史、未来命令和 K、D；它学习未来等效接触面序列，保留同一已知执行器和单边接触求解器，但不使用固定 Maxwell 状态演化。该比较检验的是明确材料状态演化相对于时序闭合模型的作用，**不是**只删除某一个接触门控的纯消融。GRU 8001 个参数，状态模型 3777 个参数。

经典积分使用已知初始松弛条件和完整过去位移；局部经典观测器仅使用末尾 0.2 s 的接触位置与力。理想模型使用真实状态与真值材料参数，属于有特权的参照。

## 数据与训练

- 新生成 384 个训练历史对、96 个验证历史对、128 个测试历史对；整个历史对及其分支一起划分。
- 每个训练/验证历史有四种未来命令分支，对应四个训练控制条件，共 3072/768 条未来轨迹。
- 多控制条件模型在 `(1200,25),(1200,80),(3600,25),(3600,80)` 下训练。单控制消融使用同样的历史、命令和样本数量，全部在 `(1200,25)` 下产生标签。
- 测试留出 `(2200,45)` 插值、`(4800,45)` 刚度外推、`(2200,110)` 阻尼外推；同一测试历史也评估四个训练控制条件。
- 三随机种子；Adam、验证集学习率衰减、相对改善阈值 0.2%，至少 1000 更新且连续 8 次验证无有效改善才停止。每 100 更新验证；初始预算上限 20000。
- 损失为力和位置的归一化预测 MSE，没有内部状态监督、未来真实接触标记或真实运动输入。

## 动作与安全指标的确切含义

所有候选先在原历史控制器下用 0.3 s 回撤到 -4 mm，确认仿真中已脱离后，在 t=0.3 s 更换控制器，再等待并压合。模型获得完整已知控制时序；材料状态持续演化、不重置。五个候选：7.5 mm 的 0.15 s 快压、0.8 s 慢压、1.6 s 缓压、额外等待 0.8 s 后快压，以及 6.5 mm 的 0.15 s 浅压。基础等待为 0.1、0.6、1.6 s。动作与 2.5–9 N 的力限制扫描沿用父目录验证集设计；本版本换用独立数据种子重新训练十二个模型，开启本版本测试前不再调整动作、限制或控制条件。

实际位置达到 4 mm 并持续 0.2 s，且发生在重新接近开始之后，才算完成。完成时间是包含回撤和等待的首次持续达标时间；命令随后继续执行并保持。力峰值始终统计完整 5 s，包含初始回撤及首次达标后的任何过冲，不会在到达目标时截断安全检查。因此过低力上限可能连初始回撤都不可行，所有方法及理想参照均受相同限制。

统一选择器选择**预测满足力上限减 0.03 N 余量且能够完成**的最快动作。没有可行动作则拒绝。执行结果以真实仿真响应计算；超力、未完成、拒绝均记为失败，综合时间成本 6 s，成功则记实际完成时间。该成本不是实际耗时，另存真实时间、峰值、成功、超力、拒绝。0.03 N 是预设共同工程余量，不是经过证明的安全保证。

反应式参照首先根据当前测量力与限制决定是否拒绝，然后以过去一采样的带噪力反馈调节命令移动速度。在验证集上从 6 种速度/力缓冲设置中选择；它拥有执行中的反馈且动作不受离散目录约束，因此与模型预测比较时单列，不把其差异解释为表征优劣。所有预测方法共用同一离散动作选择器；精确预测器也使用 0.03 N 余量。另存无余量的真实可行离散最优动作，仅用于计算非负决策代价差，不能把略优于带余量精确预测器的结果解释为超越最优解。

## 文件

- `dynamics.py`：不同控制条件的物理求解及精确分支导数。
- `models.py`：历史／当前状态编码器、条件 GRU。
- `dataset.py`、`paired_history.py`、`physics_base.py`：分支数据及复用的历史构造。
- `actions.py`、`evaluate.py`：统一选择器、反应式参照、预测和动作指标。
- `runs/transfer_v2`：完整模型、验证曲线、原始逐条件指标、成本与审计。
- `figures`：PNG、可编辑 SVG、PDF，以及图的数据源。
- `numerical_audit.py`：固定决策时真实状态，细化未来积分到 5/2.5 ms；不是重新构造整段历史。
