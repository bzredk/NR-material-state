# 第二轮：相同当前观测、不同未来响应

全部产物位于此目录。第一轮代码与结果保持原样；第二轮重用其 Python 3.11 / PyTorch 2.9.1+cu128 环境，物理核心复制后独立保存。仿真、训练与评估均在本地进行。

实验已完成：12 次训练均达到预定验证平台期。结论与数据见 [第二轮实验结论](第二轮实验结论.md)。历史状态模型能恢复受控历史对的隐藏差异，但经典积分及 0.2 s 局部观测器说明本域尚不需要神经学习来替代已知物理。

## 复现

先按[安装指南](../../../SETUP.md)准备 Python/CUDA 环境，再按[运行手册](../../REPRODUCING.md#e1--matched-histories)创建工作副本。在副本目录中运行：

```sh
python experiment.py prepare --output runs/replication
python experiment.py train --output runs/replication
python experiment.py evaluate --output runs/replication
python numerical_audit.py --output runs/replication
```

每步成功结束后再继续。输出名必须位于工作副本内。中断后运行 `python experiment.py train --resume --output runs/replication`，随后评估。达到验证平台期的模型自动跳过；触及训练上限但未达到平台期的运行会被标记为未收敛，评估入口会拒绝它。

PowerShell 也可运行 `./run.ps1 -Python python -RunName replication`。启动器使用指定的解释器；它不再依赖原电脑上的虚拟环境。

## 实验与信息边界

384 对训练、96 对验证、192 对独立测试历史；测试每对接训练范围内和留出等待两种后续条件。每对内部的历史不同，当前 `[x,v,F,u,dt]` 与整段未来命令完全一致。两条历史都从已恢复初态通过实际动力学重放生成，不在切点直接替换真实状态。

训练等待 0.2–0.5 或 1.8–2.2 s，留出等待 0.8–1.2 s；历史 3 s、未来 4.2 s、步长 0.01 s。接触和执行器模型同第一轮。少数较大历史扰动会导致提前脱离，因此仅依据历史端点／接触可行性减半扰动，保留全部种子并记录次数，不按未来差异大小筛选。

生成器真参数只用于合成与特权诊断。经典最小二乘只读第二轮训练集的带噪位置和力，得到一次物性辨识；之后全部冻结。模型学习只用历史与未来实际力／位移标签，不读取内部状态、未来接触或真实未来运动作为输入。

还包括一个测试前加入的简单对照：最近 0.2 s 已知接触段上的线性最小二乘观测器，估计窗口开始时的未知状态再推进到切点。窗口长度固定、没有调参；它不要求该短窗从完全恢复态开始。

当前切点均处于接触，满足 `k1*z1+k2*z2=(k_inf+k1+k2)*x-F`。两个状态编码器共同使用这一约束，以一个 sigmoid 标量分配支路应力；两维状态再通过已知 Maxwell 方程演化。历史模型读完整序列，当前模型只读最后一个样本，容量完全相同。

接触结构对照的两个 GRU 使用相同编码器、未来命令递推器及参数量：一个预测力，另一个预测有效自由表面，由已知接触刚度和单侧接触方程计算力。未来递推器只消费命令、时间和预测切点的读数，不消费未来传感记录；它与第一轮的逐步力反馈 GRU 架构不同，不能把两轮数值当作同架构训练延长比较。

所有学习模型均用单条未来轨迹的归一化力／位移 MSE 训练，没有配对差异损失、状态监督或测试调参。每种三个种子，按同一验证平台期规则停止，采用各自验证最优权重；不把相同训练步数当成相同收敛程度。

原始 8,000 次更新上限使 4 个 GRU 运行未达到平台期；在查看任何模型测试结果前，将保护上限延至 20,000 并从断点续训，最终均在 10,100 步以内停止。原始配置、未收敛状态和延长理由保存在 `initial_training_config.json`、`initial_cap_status/`、`validation_extension.json`。当前默认配置复现同一平台期标准和最终保护上限。

## 指标

主指标：重新压合命令开始后 1.2 s 内，预测的两条力曲线差值相对真实差值的 NRMSE。对两条历史作相同预测时严格等于 1；低于 0.5 是评估前写入的有用恢复标准。辅助报告绝对力误差、隐藏状态差异恢复和对内状态交换。完整约定见 `eval.json`。

`pair_average_oracle` 使用未来真值的对内平均，仅给出任何对内相同预测的误差下界，不是可部署基线。状态恢复比较只针对两个固定、排序后的 Maxwell 模态，不能外推成一般表征可辨识性。

## 文件

- `data.py`：受控历史对、噪声、等待划分与哈希。
- `physics.py`：独立 NumPy 物理模型。
- `differentiable.py`：固定物理的分段解析导数／伴随；仅使用模型自己预测的接触分支。通过双精度数值梯度检查。
- `models.py`：两种状态编码器与接触结构对照。
- `experiment.py`：辨识、成本测量、验证平台期训练与恢复。
- `evaluate.py`：配对指标、状态诊断、bootstrap、图表。
- `test_round2.py`、`test_intake.py`：物理、梯度、配对与真实数据接口检查。
- `numerical_audit.py`：8 个训练种子的细步长重放与重新配对诊断。
- `real_data_intake.py`、`real_metadata_template.json`：轻量 CSV 接入和力—位移诊断。
- [实机衔接协议](实机衔接协议.md)：待执行采集和未知材料机制选择标准。

固定物理循环规模很小，使用 CPU NumPy 与解析导数减少 CUDA 小算子调度；GRU 在 5070 Ti 上训练。成本报告区分训练墙钟时间、GPU 张量分配和非 GPU 计算，不将该实现效率当成科研贡献。

当前解析导数只覆盖学习所需的初始材料状态或预测力／自由表面序列；不提供对未来命令、固定物性或观测初始位姿的梯度。它可以作命令条件预测，但本轮没有实现可微动作优化器。

原始数据字段以 `[pair,branch,time,feature]` 组织；学习字段只含 `history`、`commands`、`labels`。`truth`、`oracle_z`、`oracle_initial`、`truth_contact` 均是特权评价字段。真实数据接口只做单位、时间和曲线诊断，尚不把少量真实轨迹当成新的神经训练集。
